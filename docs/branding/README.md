# MonoTask — иконка и персонаж

Текущий вариант сохраняет папку-персонажа, два овальных глаза и улыбку. Палитра обновлена по референсу: лайм Sun Glare `#D9FF00`, Exuberant Orange `#FF5429`, Blue Violet `#6B57C8`, Cloud Dancer `#F2EFEB` и Darkest Hour `#221F20`. Значения подобраны по изображению, а не по печатной спецификации Pantone.

- [Светлая иконка](MonoTask-Light.png) и [тёмная иконка](MonoTask-Dark.png) — 1254 × 1254.
- [Светлый персонаж](MonoTask-Mascot-Light.png) и [тёмный персонаж](MonoTask-Mascot-Dark.png) — иллюстрации без рамки иконки для входа и пустого пространства.
- Предыдущий шалфейный вариант сохранён в `explorations/sage/`; остальные варианты — в `explorations/`.

Перекрашено встроенным `image_gen`, без CLI/API fallback. [Финальные промпты](prompts-v4.md).

`swift scripts/export-brand-icons.swift` экспортирует исходники в Asset Catalog: iOS 1024 px, размеры и внешний шаблон macOS, адаптивные BrandLogo/BrandMascot и изображения Dock. Экспорт выполняет только масштабирование и платформенное оформление.

iOS содержит нативную тёмную вариацию AppIconPalette. Светлая и тёмная темы приложения используют AppIconLightPalette/AppIconDarkPalette; режим «Системная» возвращает основной значок. Новые имена ресурсов и номер сборки 22 обновляют иконки, закэшированные под предыдущей палитрой. Старые имена вариантов оставлены для совместимости при обновлении. На Mac тема меняет значок работающего приложения в Dock; Finder использует основной светлый значок пакета.
